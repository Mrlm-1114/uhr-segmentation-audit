# Sixteen evaluation checks

Record evidence and mark each item confirmed, partial, unresolved or inapplicable.
Use the evidence fields to record the assessment for each literature entry.

1. Dataset source, version, split counts, overlap and duplicate policy.
2. Class order, label mapping, ignore value and zero-label handling.
3. Unknown-class treatment in error accumulation and final averaging.
4. Pooled versus imagewise aggregation and absent-class policy.
5. Published-number source: paper version, page/table and evidence strength.
6. Backbone, initializer, training recipe, iterations and seed.
7. Validation route/checkpoint selection, ties and test-use policy.
8. Complete inference route, scale, crop/stride, interpolation and TTA.
9. Timing start/end tensors and included CPU/GPU operations.
10. Warm-up, repeats, synchronization and raw per-call observations.
11. GPU model, framework versions, hardware session and thread settings.
12. Precision, OOM and route availability without substitutions.
13. Peak allocated/reserved memory and measurement scope.
14. Per-seed results, sample size, mean and sample standard deviation.
15. Cross-paper equivalence assumptions, recovery anchors and formulas.
16. Source/configuration hashes, raw records, reconstruction scripts and access terms.
